# Security

## Report a vulnerability

Do not open a public issue for a vulnerability. Use **Report a vulnerability** on the Security tab of this repository.
GitHub keeps the report private between you and the maintainer.

Give:

- the commit or version that you tested,
- the steps to reproduce, with dummy data,
- the result that you observed.

## Supported versions

Halinka has no release yet. Only the `main` branch gets fixes.
